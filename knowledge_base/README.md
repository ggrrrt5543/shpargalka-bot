# 📚 База знаний (Knowledge Base)

Положите сюда файлы для RAG-поиска. Бот будет искать в них
релевантную информацию перед ответом на вопрос.

## Поддерживаемые форматы
- `.pdf` — учебники, методички
- `.md` — конспекты, заметки
- `.txt` — любой текст

## Структура папок (по предметам)

```
knowledge_base/
├── math/           ← математика
├── physics/        ← физика
├── chemistry/      ← химия
├── literature/     ← литература
├── history/        ← история
├── english/        ← английский
├── informatics/    ← информатика
├── biology/        ← биология
├── social/         ← обществознание
└── general/        ← общее (без привязки к предмету)
```

Если файл лежит в подпапке предмета — он будет использоваться
только для вопросов по этому предмету (при выборе предмета пользователем).

## Переиндексация

Индексация происходит автоматически при запуске бота.
Для ручной переиндексации: команда `/reindex` (только для админа)
или кнопка «🔄 Реиндекс» в админ-панели.
