# 📋 Инструкции по загрузке проекта на GitHub

## 🚀 Пошаговая инструкция

### 1. Создайте репозиторий на GitHub

1. Зайдите на [GitHub](https://github.com)
2. Нажмите на "+" → "New repository"
3. Название репозитория: `shpargalka-bot`
4. Описание: `Telegram-бот для решения учебных задач с помощью AI`
5. Выберите "Public" или "Private"
6. **Не ставьте галочки** "Add a README file", "Add .gitignore", "Choose a license"
7. Нажмите "Create repository"

### 2. Инициализация Git в проекте

Откройте терминал в папке проекта:

```bash
cd "C:\Users\clabo\OneDrive\Desktop\shpargalka-bot"
```

### 3. Настройка Git (если впервые)

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш.email@example.com"
```

### 4. Инициализация репозитория

```bash
git init
git add .
git commit -m "Initial commit: Шпаргалка-бот - Telegram бот для решения задач"
```

### 5. Подключение к GitHub

Скопируйте URL из созданного репозитория на GitHub и выполните:

```bash
git remote add origin https://github.com/ВАШ_НИК/shpargalka-bot.git
git branch -M main
git push -u origin main
```

### 6. Проверка загрузки

Зайдите в свой репозиторий на GitHub - все файлы должны появиться там!

```bash

git add .

git push origin feature/новая-функция
```

## ⚠️ Важные замечания

1. **Никогда не загружайте `.env` файл** с токенами на GitHub!
2. Все токены должны быть только в локальном `.env` файле
3. Перед загрузкой убедитесь, что в `.gitignore` есть строка `.env`
4. Для совместной работы используйте Pull Requests
